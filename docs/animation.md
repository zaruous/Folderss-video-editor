# 애니메이션 효과 (#4)

꾸민 글자·아트 요소·사진·동영상 클립이 나타나고, 움직이고, 사라지게 하는 효과다. 목록에서 골라 넣고 방향·단위·길이 같은 설정만 고친다(키프레임을 찍지 않는다).

## 1. 지금 되는 것

| 분류 | 효과(사라지기 이름) | 설정 |
|---|---|---|
| 나타나기·사라지기 | 서서히, 날아오기(날아가기, 8방향), 확대(축소), 튀어 오르기(튀어 나가기, 4방향), 닦아내기(8방향), 돌며 나타나기(돌며 사라지기, 시계 방향·반대, 회전 각도), 타자기(타자기 지우기 — 글자 클립), 모여들기(흩어지기 — 글자 클립, 거리), 떠오르기(흐려지며 가라앉기, 거리 px), 커지며 돌기(작아지며 돌기, 시계 방향·반대, 회전 각도), 가운데서 갈라지기(가운데로 닫히기, 좌우로·위아래로), 흐림에서 선명하게(흐릿하게 사라지기, 흐림 px), 그려지기(지워지기 — 선·화살표·동그라미 치기·밑줄 요소) | 단위(글자 클립: 한 번에·단어별·글자별), 사이 지연(%), 길이, 지연, 이징 |
| 사라지기만 | 떨어지기(시계 방향·반대, 기울기) | 단위, 사이 지연, 길이, 지연, 이징 |
| 강조 | 맥박(커지는 정도), 흔들기(가로·세로, 폭), 회전(각도, 방향), 크게·작게(크기 %), 투명도 바꾸기(불투명도 %), 색 바꾸기(색, 세기 %), 광선 깜빡임(색, 광선 크기 px), 물결(글자 클립 — 단어별·글자별, 높이 %), 굵게 깜빡이기(글자 클립 — 한 번에·단어별·글자별, 굵기 %) | 길이(한 번), 지연, 반복(0 = 클립 끝까지 — 맥박·흔들기·회전·광선 깜빡임·물결·굵게 깜빡이기), 이징 |

- 한 클립에 나타나기 1 + 강조 8개까지 + 사라지기 1.
- 시간: 나타나기는 클립 시작 + 지연부터, 사라지기는 클립 끝 − 지연에서 끝난다(짧은 클립에서 겹치면 사라지기를 나타나기 뒤로 줄인다). 강조는 시작 + 지연부터 한 번의 길이마다 되풀이한다.
- 사라지기는 나타나기를 거꾸로 돌린 움직임이다. 날아가기 "왼쪽"은 왼쪽으로 나가고, 타자기 지우기는 뒤 글자부터 지우고, 지워지기는 그린 차례를 거꾸로 거둔다. 떨어지기는 사라지기에만 있다(서서히 끝 이징을 거꾸로 돌려 점점 빨라진다).
- 크게·작게, 투명도 바꾸기, 색 바꾸기, 회전은 끝난 뒤 그 값에 남는다(회전이 360°의 배수면 제자리). 맥박·흔들기·광선 깜빡임·물결·굵게 깜빡이기는 제자리로 돌아온다.
- 색 바꾸기는 밝기를 지키며 물들인다: (1 − 세기) × 원래 색 + 세기 × 색 × 밝기(0.299R + 0.587G + 0.114B). 흰색은 그 색, 검은 윤곽은 검정 그대로다.
- 떠오르기 거리·흐림·광선 크기는 프로젝트 픽셀이다(글자별로 움직일 때도 같은 크기). 물결 높이·굵기는 글자 크기의 %다.
- 이징: 일정, 서서히 시작(p²), 서서히 끝(1 − (1 − p)²), 둘 다(smoothstep — 전환 효과의 이징과 같은 식), 튕김, 탄성.

## 2. 화면

- **속성 패널 [애니메이션] 탭**: 분류별 썸네일(마우스를 올리면 움직임). 그 클립에 넣을 수 있는 효과만 보인다(글자 전용·그려지기·사라지기 전용). 누르면 넣는다 — 나타나기·사라지기는 바꾸고, 강조는 하나 더한다. 아래에 넣은 효과의 설정(색 효과는 색 칸, 글자 전용 강조는 단위·사이 지연)과 [빼기], 맨 아래 [미리 보기](이 클립 구간만 재생).
- **타임라인**: 클립 아래 가장자리 안에 나타나기(초록)·사라지기(주황) 띠, 강조는 점선. 띠 안쪽 끝의 흰 손잡이를 끌면 길이를 바꾼다.
- 재생·내보내기 전에 글자별 장을 그리는 동안 상태 줄·내보내기 창에 "애니메이션을 그리는 중… n/m"이 나온다.

## 3. 그리는 방법

미리 보기·재생·내보내기 모두 `RenderGraph`에서 같은 그래프를 만든다(미리 보기 = 내보내기). 애니메이션이 없는 클립은 그래프 글이 예전과 같다.

### 한 번에 움직이는 것 — FFmpeg 시간식 (`Core/AnimationMotion.cs`, `Core/RenderGraph.Animation.cs`)

동영상·사진·꾸민 글자·아트 요소가 같은 필터로 움직인다. 식은 `MotionExpr` 나무 하나에서 C# 값과 FFmpeg 식 글을 함께 만든다.

| 무엇 | 필터 |
|---|---|
| 시각 | 클립 안 장 번호 `round(t*fps)+시작 장` — 초로 계산하면 구간 끝 장의 진행이 0.9999…가 되어 overlay가 버림한 위치가 한 픽셀 어긋났다. 장 번호는 정수라 시작·끝에서 정확히 0·1 |
| 닦아내기 | 틀 크기를 모르는 그림(꾸민 글자 PNG·맞춤 결과)이라 투명하게 두 배로 넓히고(`pad`) 원래 크기로 자르고(`crop`, x·y는 장마다) 반대로 한 번 더. 가운데서 갈라지기는 양쪽 닦아내기 둘이 겹친 곳((1 + e) / 2씩, 처음 장은 0) |
| 흐림 | 장마다 시그마를 바뀌는 장에서만 `sendcmd`로 `gblur@blN`에 보낸다(세로 시그마 `sigmaV`도 — 명령으로 `sigma`만 바꾸면 세로는 처음 값에 남는다). 알파를 곱한 색으로 흐리고(`premultiply`) 그 곱하기는 흐린 장에서만 `enable`로 켠다 — 곱하기는 255를 254로 바꿔 다 나타난 장이 정지 그림과 달라진다 |
| 색 바꾸기 | `colorchannelmixer@ctN`의 3×3 값을 바뀌는 장에서만 `sendcmd`로(명령 하나에 아홉 값). 시작 전만 그리면 넣지 않는다 |
| 광선 | 그림을 나눠(`split`) 광선 색으로 칠하고(`lutrgb`) 알파를 흐린(시그마 = 크기 / 2) 층을 밑에 깔고(`overlay`) 그 층의 불투명도를 `sendcmd`로 |
| 회전 | `rotate` 각도 식. 출력은 대각선까지 넓힌 크기(각도가 바뀌어도 잘리지 않고 가운데는 그대로). 빈 곳은 투명하게 칠한다(`c=none`은 칠하지 않아 앞 장의 그림이 꼬리처럼 남았다). 그리는 구간 내내 각도가 같으면 그 각도 하나로(0°면 넣지 않음) |
| 불투명도 | 시간식을 받는 알파 필터가 없어 장마다 값을 계산해 바뀌는 장에서만 `sendcmd`로 `colorchannelmixer@anN`의 `aa`를 바꾼다(명령은 반 장 앞 시각) |
| 크기 | 체인 맨 끝 `scale=…:eval=frame` — 장마다 크기가 바뀌므로 뒤에는 overlay만 둔다 |
| 위치 | `overlay` x·y 식. 날아오기·떨어지기는 `overlay_w`·`main_w`로 화면 밖(오른쪽 가장자리가 화면 왼쪽 끝 등)까지, 흔들기·떠오르기는 프로젝트 픽셀 × 출력 배율, 크기가 0에 가까우면 화면 밖으로 치운다(1픽셀 점이 남지 않게) |

- 차례: 닦아내기 → 흐림 → 색 바꾸기 → 광선 → 회전 → 불투명도 → 크기, 그다음 overlay. 광선은 색 바꾸기에 물들지 않는다.
- 그림을 넓힐 때(흐림·광선의 번질 자리, 회전 캔버스) 바탕(yuv420)의 overlay는 자리를 짝수로 내리므로 반폭을 짝수로 넓힌다(회전 캔버스는 4의 배수, 먼저 투명하게 2픽셀씩 — `rotate`는 가장자리 밖 한 픽셀을 가장자리 색으로 칠한다). 그래야 움직임이 끝난 장이 정지 그림과 같은 자리에 놓인다.
- 흐림·광선의 번질 자리는 그리는 구간과 상관없이 클립 전체에서 정한다 — 재생 헤드 한 장과 내보내기가 같은 크기·자리. 다 나타난 장은 자리가 같고, 넓힌 투명한 가장자리 때문에 바탕의 색 나누기가 가장자리 한 픽셀의 색만 조금 바꾼다.

### 그리개가 장마다 그리는 것 (`Core/TextAnimation.cs`, `Ui/StyledTextRasterizer.Animation.cs`, `Ui/StyledTextRasterizer.cs`)

단어·글자별 나타나기·사라지기, 글자 전용 강조(물결·굵게 깜빡이기 — 한 번에여도 글자 모양이 바뀐다), 요소의 그려지기.

- 글자 나누기 `TextUnits`: StringInfo 글자 요소 가운데 빈칸이 아닌 것. 한글은 음절이고 풀어 쓴 자모·결합 문자·이모지 이음도 한 글자다. 그리개도 줄을 나눈 뒤 같은 차례로 센다.
- 그리개 요청 `TextImageRequest.Animation`(나타나기·사라지기·글자 전용 강조·구간·장 번호)으로 그 장을 그린다. 요소마다 윤곽을 따로 만들어 줄 안 자리(커닝 그대로)에 놓고, 단위 가운데 기준으로 크기·회전 뒤 옮긴다. 그라데이션은 글 전체 상자 기준. 흐린 묶음은 묶음마다 따로 그려 흐림 효과를 걸고, 굵게는 윤곽을 둥근 이음으로 넓힌 것과 합친다(채우기·윤곽선·그림자·광선이 모두 굵어진다).
- 강조는 나타나기 위에 더한다. 물결·굵게 깜빡이기는 한 번 안에서 단위마다 사이 지연만큼 늦게 솟았다(굵어졌다) 돌아온다 — 한 번의 시작·끝 장은 모두 제자리라 되풀이가 이어진다.
- 그려지기: 요소 윤곽 `ArtGeometry.Outline(모양, 배율, drawn)` — 선·화살표는 꼬리부터 x = drawn × 너비에서 자르고(점선은 그 앞 대시만, 머리도 그린 만큼), 동그라미 치기·밑줄은 붓 선의 앞 drawn만큼(앞끝은 붓이 지나는 굵기). drawn이 1이면 예전 윤곽과 같은 계산이다. 그린 비율은 구간 밖에서 정확히 1(튕김 이징의 끝 값이 1에서 조금 어긋나도 다 그린 장 = 정지 그림). 그리는 도중에도 그림 크기·그라데이션·반사 바닥은 다 그린 모양 기준.
- 한 클립의 모든 장은 같은 크기(그릴 수 있는 모든 모습 — 움직이는 장과 강조마다 한 번 — 의 범위를 모아 넓힌다) — FFmpeg `concat`이 같은 크기를 요구한다.
- 그래프: `[0, 나타나기)` 첫 장 · 나타나기 장들 · 쉬는 동안 · 사라지기 장들 · 사라진 장을 `concat`으로 잇는다. 쉬는 동안은 글자 전용 강조의 구간으로 나눠
  - 강조가 없으면 쉬는 장 하나,
  - 강조 하나면 그 강조 한 번만(나타나기·사라지기는 다 나타난 모습으로 — 요청의 `Solo`) 그린 그림 묶음을 `-loop 1`로 되풀이해 `trim`으로 한 번 안의 차례부터 고른다 — 클립 끝까지 되풀이해도 한 번 길이만큼만 그린다,
  - 둘 이상 겹치면 장마다 그린다.
- 여러 장은 그림 묶음 입력(`-framerate R -f image2 -pattern_type sequence -i …-i%05d.png`, 임시 경로의 `%`는 `%%`)에서 `trim`으로 고르고, 한 장(재생 헤드)은 그 장 그림 하나만 그린다.
- 그리개가 없거나(시험)·긴 글이면 한 번에 움직이는 비슷한 모습으로 그린다(타자기·그려지기 = 왼쪽부터 닦아내기, 흩어지기 = 서서히, 물결 = 글 전체가 솟았다 내려앉기, 굵게 깜빡이기 = 조금 커졌다 돌아오기).

### 캐시

- 장 이름은 `styled-text\sa-<묶음 키>-i00012.png`(나타나기 12번 장)·`-o00003`(사라지기)·`-s`(쉬는 장)·`-w0-00004`(0번 강조 한 번의 4번째 장)·`-m00020-00003`(강조가 겹친 20번 장부터의 3번째). 묶음 키는 꾸민 글자 요청 + 애니메이션 설정 + 구간의 SHA-256이라 설정을 바꾸면 새로 그리고, 되돌리면 이미 그린 파일을 다시 쓴다. 강조가 없는 묶음의 키는 예전과 같다. 위치·크기·회전은 그래프에서 바뀌므로 다시 그리지 않는다.
- 꾸민 글자 PNG 캐시와 같은 폴더·용량 상한·정리 규칙(끝난 프로세스의 폴더는 시작할 때 지운다).

### 미리 보기 도우미

입력 옵션은 그대로(`-loop -framerate -f -pattern_type -i`)다. 도우미가 `-pattern_type sequence`를 그림 한 장처럼 되풀이하던 것을 ffmpeg.exe와 같게 고쳤다 — 디멀티플렉서에 `framerate`를 넘기고 장마다 읽으며, 바뀜 확인은 첫 장(0번) 파일로 한다. 열 때 마지막 장 번호가 정해지므로 묶음은 풀에 두고 다시 쓰지 않는다(PNG라 다시 여는 비용이 작다). 그림 묶음의 `-loop 1`(강조 한 번 되풀이)은 끝에서 처음으로 되감아 시각을 이어 붙이는 지금 방식으로 ffmpeg.exe와 같다(시험에서 차이 0).

## 4. 저장 형식

- `Clip.Animations`(없으면 저장 글에 키가 없다). 항목: `Kind`(In·Emphasis·Out), `Effect`, `Direction`, `Unit`, `Stagger`(%), `Duration`·`Delay`(프레임), `Repeat`, `Ease`, `Amount`, `Color`("#RRGGBB" — 색 바꾸기·광선 깜빡임만).
- 애니메이션이 든 클립이 있을 때만 형식 4(아트가 있든 없든), 없으면 예전처럼 3(아트)·2. 읽기는 4까지. 남은 효과·`Color`도 형식 4 안에서 더했다(형식 4는 아직 배포 전).
- 읽을 때 규칙 안으로 고친다: 모르는 효과 이름(새 판)은 그 항목만 버리고, 분류가 맞지 않거나(사라지기 전용을 나타나기로 등) 글자 전용 효과가 다른 클립에, 그려지기가 선·화살표·동그라미 치기·밑줄이 아닌 클립에 있으면 버린다. 강조는 글자 전용만 단위를 나누고, 타자기·흩어지기·물결은 한 번에로 저장돼도 글자별로 읽는다. 색은 "#RRGGBB"로(알파는 뺌, 잘못된 글은 기본 색). 자막 트랙 큐·분리한 사운드는 애니메이션이 없다.
- 클립을 나누면 왼쪽은 사라지기를, 오른쪽은 나타나기를 뺀다(강조는 둘 다). 프레임 레이트를 바꾸면 길이·지연도 바꾼다.

## 5. 남은 것

- 2단계: 이동 경로(직선·호·원·사용자 경로), 플레이어 조작 핸들 확장(회전 손잡이·이동 경로 점), 사용자 키프레임.
- 3단계 후보: 효과 묶음 스타일, 조각이 맞물리는 조립형 연출.
- 이 단계에 없는 효과: 바로 나타나기.
