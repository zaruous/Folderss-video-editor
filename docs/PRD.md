# Folderss 동영상 편집기 (Video Editor 플러그인) — PRD

ECC `plan-prd` 형식. 요구 사항만 적고 구현 방법은 [`plan.md`](plan.md)에 둔다.

## Problem
Folderss에서 영상 파일을 찾아 보는 사용자가 짧은 영상을 자르고 이어 붙이려면 별도 영상 편집기를 열고, 파일을 다시 가져오고, 프로젝트를 따로 관리해야 한다. 간단한 컷 편집에도 프로그램 전환과 가져오기 단계가 반복된다.

## Evidence
- Assumption — needs validation via 사용자 인터뷰(이 플러그인 요청자 본인의 실제 편집 작업 3건 관찰).

## Users
- **Primary**: Folderss로 작업 폴더를 관리하면서 화면 녹화·시연 영상·짧은 홍보 영상을 직접 자르고 붙이는 개발자·SI 담당자. 계기: 폴더에서 영상 파일을 발견하고 "앞뒤만 자르고 몇 개 이어서 내보내야" 할 때.
- **Not for**: 색보정·모션 그래픽·AI 생성이 필요한 전문 영상 제작자 (전문 편집기를 그대로 쓰는 게 맞다).

## Hypothesis
We believe **Folderss 안에서 익숙한 편집기 배치·단축키로 컷 편집하고 MP4로 내보내는 플러그인**이 **별도 편집기로 옮겨 가는 번거로움**을 없앨 것이다 — 대상: **Folderss 사용자 중 간단한 영상 편집을 하는 사람**.
We'll know we're right when **영상 3개를 가져와 앞뒤를 자르고 이어 1080p MP4로 내보내는 작업을 영상 편집기를 써 본 사람이 설명 없이 5분 안에 끝낸다**.

## Success Metrics
| Metric | Target | How measured |
|---|---|---|
| 기본 컷 편집 작업 시간(가져오기 3개 → 다듬기 → 내보내기) | 5분 이내, 안내 없이 | 사용자 시연 관찰 |
| 내보낸 영상의 길이·컷 위치 정확도 | 타임라인과 ±1프레임 | 자동 시험(ffprobe로 길이·프레임 비교) |

| 타임라인 조작 반응 | 클립 100개에서 끌기·확대가 끊김 없이 | 헤드리스 시험 측정 |

## Scope
**MVP** — 미디어 가져오기(파일·Folderss 폴더) → 다중 트랙 타임라인에서 배치·이동·다듬기·분할·리플 삭제(흔히 쓰는 편집기 단축키) → 미리 보기 재생 → 프로젝트 저장/열기 → MP4 내보내기.

**Out of scope**
- AI 기능(대화형 도우미·영상 늘리기·배경 지우기) — 서버·모델 필요, 가설과 무관. 음성 인식 자막은 로컬 모델(whisper.cpp)로 넣었다 — [speech-to-text.md](speech-to-text.md)
- 스톡 미디어·템플릿·스티커·효과 상점 — 외부 서비스·에셋
- 키프레임 애니메이션·펜 도구·색보정·LUT·카메라 추적 — MVP 이후
- 복합 클립·듀얼 타임라인·하위 프로젝트 — MVP 이후
- 배치 모드 9종·플레이어 떼어 내기 — 기본 배치 하나로 시작
- 화면 녹화·멀티캠 — 별도 기능
- 다른 편집기의 프로젝트 파일 읽기 — 형식이 비공개
