# 음성 인식 자막 (whisper.cpp, 이 PC에서만)

내레이션 영상에 붙일 자막을 편집기 안에서 만든다. 지금까지는 다른 도구로 SRT를 만들어 [자막 가져오기]로 넣어야 했다.
PRD에서 AI 기능은 서버·모델이 필요해 뺐다. 음성 인식만은 서버 없이 로컬 모델로 할 수 있어서 범위에 넣는다.

## 1. 쓰는 법

- [파일 > 음성 인식으로 자막 만들기…]를 누르거나, 타임라인 클립의 오른쪽 메뉴에서 [이 클립 소리로 자막 만들기…]를 고른다.
- 고른 클립 중 소리가 있는 것이 있으면 그 클립만 인식한다. 없으면 타임라인 전체 소리(모든 트랙을 섞은 것)를 인식한다.
  배경 음악이 섞이면 시각이 밀리고 틀린 말이 늘어서, 내레이션 클립을 고르는 것을 권한다.
- 말(한국어·자동·English·日本語·中文)과 모델을 고르고 [자막 만들기]를 누른다.
- 결과는 맨 위 새 자막 트랙에 큐로 들어간다. 시각은 타임라인 위치(클립이면 클립 시작·속도에 맞춤)이고, 틀린 글은 큐를 골라 속성에서 고친다.

## 2. 정한 것

1. **엔진: whisper.cpp CLI(`whisper-cli.exe`).**
   - 이 PC에서만 돌아서 소리를 인터넷으로 보내지 않는다. 라이선스는 MIT이고 모델 가중치도 MIT다.
   - 처음 한 번 GitHub ggml-org/whisper.cpp 릴리스의 `whisper-bin-x64.zip`(CPU 판, 약 9MB)을 받는다.
     - 릴리스 API의 SHA-256(digest)이 맞을 때만 쓴다.
     - `whisper-cli.exe`와 whisper·ggml DLL만 데이터 폴더`\whisper`에 푼다.
   - whisper.cpp는 버전 태그(v1.x)에는 파일이 없고, 같은 때 만든 빌드 릴리스(bNNNN)에 붙인다.
     그래서 최신 정식 버전과 6시간 안에 만든 빌드를 고르고, 없으면 파일이 있는 가장 새 릴리스를 고른다.
   - 받은 뒤 `--version`을 돌려 본다. Microsoft Visual C++ 재배포 패키지(x64)가 없어 시작하지 못하면(0xC0000135) 설치 주소를 알린다.
2. **모델: Hugging Face ggerganov/whisper.cpp의 양자화 모델 셋.** 크기와 SHA-256은 코드에 고정해 두고, 받은 파일과 맞춰 본다.

   | 이름 | 파일 | 크기 | 2분 30초 내레이션(12코어) |
   |---|---|---|---|
   | 보통(추천, 기본) | ggml-small-q5_1.bin | 190MB | 약 30초. 대체로 맞고 가끔 틀림 |
   | 정확 | ggml-large-v3-turbo-q5_0.bin | 574MB | 약 1분 55초. 단어가 가장 정확 |
   | 빠름 | ggml-base-q5_1.bin | 60MB | 빠르지만 한국어는 자주 틀림 |

3. **인식 순서**
   1. FFmpeg로 16kHz 모노 WAV를 만든다.
      - 클립이면 원본의 클립 구간만 꺼낸다.
      - 타임라인이면 렌더 그래프의 소리를 섞어 쓴다.
   2. `whisper-cli -m 모델 -f wav -l 말 -t 스레드 -osrt -of 이름 -pp`를 돌린다.
      - 진행률은 표준 오류의 `progress = N%`에서 읽는다.
      - 스레드는 코어 하나를 남기고 8개까지 쓴다.
   3. SRT를 읽어 큐를 타임라인 시각으로 옮긴다(클립 시작 + t / 속도). 클립 밖은 자르고 버린다.
   4. 말이 아닌 소리 표시는 뺀다. 괄호 하나로 감싼 `[음악]`·`(박수)`, 그리고 `♪`처럼 음악·잡음에서 모델이 지어내는 것이다.
   5. 두 문장 이상을 한 큐로 묶은 긴 큐(32자 넘음)는 문장·쉼표 끝에서 나누고, 시간은 글자 수에 비례해 나눈다.
4. **임시 파일**: WAV·SRT는 임시 폴더에 무작위 이름으로 쓰고 끝나면 지운다. 클립 Id·파일 이름은 쓰지 않는다.

## 3. 시험

- `SpeechTests`(네트워크·whisper 없이 CI에서 돈다)
  - 릴리스 고르기와 진행률 읽기를 본다.
  - 큐 시각 옮기기, 잡음 표시 빼기, 긴 큐 나누기를 본다.
  - 가짜 응답으로 내려받기·압축 풀기(필요한 파일만, 폴더 탈출 없음)를 보고, SHA-256이 다르면 거부하는지 본다.
- `SpeechIntegrationTests`와 UI 시험의 인식 부분은 `FOLDERSS_VE_WHISPER`를 줄 때만 돈다.
  이 값은 `whisper-cli.exe`와 DLL이 있고 `models\ggml-small-q5_1.bin`이 든 폴더다.

## 4. 범위 밖(다음에)

- GPU 판(CUDA, 270~690MB), 단어 단위 시각(노래방 자막), 화자 나누기.
- 인식한 자막으로 사진 자동 배치(제안 C).
