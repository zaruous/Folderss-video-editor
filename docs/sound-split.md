# 사운드 분리 — 영상과 사운드를 나눠 따로 쓰기 (이슈 #5)

원본 영상에 든 음악·소리를 따로 쓸 수 있게, 영상과 사운드를 나눠 각자의 트랙에 놓는다.
나눈 두 클립은 링크되어 함께 움직이고, 링크를 풀면 어긋난 만큼이 보인다. 다시 합치거나 사운드만 파일로 뽑을 수도 있다.
이슈: [#5](https://github.com/zaruous/Folderss-video-editor/issues/5).

## 1. 쓰는 법

| 곳 | 항목 | 하는 일 |
|---|---|---|
| 타임라인 클립 오른쪽 메뉴 · 편집 메뉴 · 도구 막대 | **사운드 분리** (Ctrl+Alt+D) | 고른 동영상 클립의 소리를 오디오 트랙(같은 시간에 비어 있는 트랙, 없으면 새 트랙)으로 나누고 영상 클립의 소리를 끈다. 두 클립은 링크된다 |
| 미디어 패널 오른쪽 메뉴 | **사운드 분리해서 배치** | 소리가 있는 동영상에서만 보인다. 재생 헤드에 영상은 동영상 1(주 트랙 — 마그네틱이면 가까운 경계), 사운드는 오디오 트랙에 놓는다. 여러 개를 고르면 차례로 이어 놓는다(사진·오디오는 건너뜀). 실행 취소 한 번에 모두 사라진다 |
| 타임라인 클립 오른쪽 메뉴 | **사운드 합치기** | 링크된(또는 같은 원본·같은 구간인) 영상·사운드를 함께 고르면 보인다. 사운드 클립을 지우고 영상 클립의 소리를 다시 켠다 |
| 타임라인 클립 오른쪽 메뉴 | **링크 해제** / **다시 링크** | 영상·사운드를 따로 움직이게 한다 / 지금 자리 그대로 다시 묶는다 |
| 타임라인 클립 오른쪽 메뉴 | **싱크 맞추기 (+3f)** | 짝과 어긋났을 때 보인다. 사운드를 영상에 맞춰 옮긴다 |
| 미디어 패널 · 타임라인 클립 오른쪽 메뉴 | **사운드를 파일로 저장…** | 사운드만 파일로 뽑아 미디어 목록에 더한다(5절) |

- 타임라인 클립에는 "(사운드 분리 · 링크)", 사운드에는 "(링크)"가 붙는다. 속성 패널의 [소리] 탭은 분리한 영상 클립에 "사운드를 분리해 오디오 트랙에 두었습니다"를 보인다.
- 링크된 클립을 하나 누르면 둘 다 골라진다. 속성 패널은 누른 쪽을 보인다(사운드를 누르면 사운드의 음량·페이드).
- **Alt를 누른 채 끌기 시작하면** 그 한 번만 그 클립만 옮기거나 다듬는다(붙기도 꺼짐). 끄는 도중에 누른 Alt는 지금처럼 붙기만 끈다.

## 2. 링크 규칙

모델은 `Clip.LinkId`(짝 둘이 같은 값)와 `Clip.Unlinked`(링크 해제 — 짝은 남기고 따로 움직임)다. 로직은 Core `ClipLinks`(`Core/SoundSplit.cs`)에 있고 `TimelineEdits`가 편집마다 부른다.

1. **짝**은 영상(소리를 끈 동영상 클립, `AudioDetached`) 하나와 사운드(같은 원본의 소리만 쓰는 오디오 트랙 클립, `AudioOnly`) 하나다.
2. **함께 하는 편집**: 고르기, 옮기기, 다듬기(같은 원본 길이만큼), 분할(오른쪽 조각 둘은 새 `LinkId`의 짝), 삭제, 속도.
   - 늘이는 다듬기에서 짝이 옆 클립에 막혀 덜 늘면 이끄는 쪽도 그만큼만 늘어 두 길이가 같다(마그네틱 주 트랙이면 뒤 영상도 다시 붙음). 짝이 잠긴 트랙이면 이끄는 쪽만 늘어난다.
3. **따라가기**: 편집 전 두 클립의 "원본 0프레임이 타임라인에 오는 자리"(`Start − SourceIn / Speed`, 다듬기·분할로는 바뀌지 않음)의 차이를 기억했다가, 편집 뒤 달라진 짝은 한쪽을 옮겨 되돌린다.
   - 주 트랙에 끼워 넣거나 지워 영상이 밀리거나 당겨져도, 빈틈 닫기·마그네틱 켜기·프레임 레이트 바꾸기에도 사운드가 따라간다.
   - 이끄는 쪽: 마그네틱 주 트랙의 클립 → 직접 고친 클립 → 혼자 움직인 클립 → 영상.
   - 마그네틱 주 트랙의 영상은 경계에 붙어 자리가 정해지므로, 그 영상과 링크된 사운드를 옮기거나 다듬거나 속도를 바꾸면 영상을 바꾸고 사운드가 따라간다.
4. **덮어쓰지 않음**: 따라가는 클립의 자리에 다른 클립(배경 음악 등)이 있으면 덮지 않고 같은 종류의 빈 트랙(없으면 새 트랙)으로 간다. 따라갈 클립은 모두 들어 낸 뒤 놓아 서로 덮지 않는다(두 영상을 바꿔 놓으면 사운드도 바꿔 놓임).
5. **잠긴 트랙**의 짝은 움직이지 않는다(다듬기·속도·삭제도). 그러면 어긋남으로 보이고, 짝을 지웠으면 남은 클립의 링크를 푼다.
6. 잘라 내기·복사한 짝은 붙여 넣을 때 사본끼리 새로 링크한다(영상을 먼저 놓고, 주 트랙 경계로 밀렸으면 사운드도 그만큼). 그래서 사운드가 0 앞으로 가야 하면 0 앞 부분을 잘라 싱크를 지키고(`ClipLinks.PlaceInSync`), 통째로 0 앞이면 붙여 넣기를 거절한다.
7. 사본(`CloneWithNewId`)은 짝을 넘겨받지 않는다 — 나눈 조각·덮어써서 잘린 조각·붙여 넣은 사본은 짝을 따로 정한다.

## 3. 어긋남 표시·싱크 맞추기

- 짝의 시간이 다르면 두 클립의 오른쪽 위에 빨간 배지를 보인다. 값은 **이 클립이 짝보다 늦은 만큼**이라 두 클립의 부호가 반대다(사운드 `+5f`, 영상 `−5f`).
- 1초 안이면 프레임(`+3f`), 넘으면 `−0:00:01.05`(시:분:초.프레임 — 타임코드와 같은 초·프레임 자리). 빼기는 U+2212.
- 링크를 풀고 옮겼을 때, Alt로 한쪽만 옮겼을 때, 잠긴 짝이 따라오지 못했을 때 생긴다. 링크된 채 어긋난 짝은 그 차이를 지키며 함께 움직인다.
- **싱크 맞추기**는 사운드를 옮긴다(영상은 보통 주 트랙에 있다). 0 앞으로 나가는 부분은 잘라 내고, 자리에 다른 클립이 있으면 빈 오디오 트랙으로.
- 화면 낭독기·시험에는 클립 이름 끝에 "· 링크" / "· 링크 해제"와 "· 어긋남 +5f"를 붙인다.

## 4. 사운드 합치기

- 대상: 같은 `LinkId`인 짝(링크를 풀었어도), 또는 **둘 다 링크가 없고** 같은 원본·같은 구간(시작·원본 구간·속도가 같음)인 영상·사운드 — 링크가 없던 예전 프로젝트의 분리 클립도 합친다.
- 사운드 클립을 지우고 영상 클립의 `AudioDetached`를 끈다. 사운드에서 고친 음량·페이드는 영상으로 옮긴다(분리한 동안 들은 소리 그대로).
- 고치지 않았으면 렌더 그래프가 분리 전과 똑같다(시험: 그래프 비교 + FFmpeg로 그린 PCM이 바이트까지 같음).

## 5. 사운드를 파일로 저장

| | 미디어 패널 | 타임라인 클립 |
|---|---|---|
| 구간 | 파일 전체 | 클립 구간(In~Out = `SourceIn`~`SourceOut`) |
| 속도 1 | 다시 인코딩하지 않고 꺼냄(`-map 0:a:0 -vn -c:a copy`) | 같음(`-ss`·`-t`를 입력 앞에 — 패킷 경계에서 잘림) |
| 속도 ≠ 1 | — | WAV로 다시 인코딩(`atempo`, 0.5보다 느리면 여러 번) |

- 그릇은 코덱에 맞춘다(Core `SoundExtract.ExtensionFor`): aac → `.m4a`, mp3 → `.mp3`, opus → `.opus`, vorbis → `.ogg`, flac → `.flac`, pcm → `.wav`, 그 밖 → `.mka`. 저장 창에서 WAV를 골라도 된다.
- 그대로 꺼내지 못하면(그릇이 코덱을 받지 않음 — 빅 엔디언 PCM을 WAV에 등) 같은 이름의 `.wav`(pcm_s16le)로 저장하고 알린다. `.wav`로 고르면 PCM 원본만 그대로 담고 그 밖은 PCM으로 바꾼다(다른 코덱을 담은 WAV는 못 여는 프로그램이 많다).
- 옆의 임시 이름(`이름.part-xxxxxxxx.확장자`)에 쓰고 다 되면 바꿔 넣는다 — 실패해도 덮어쓰기로 고른 원래 파일이 남는다. 실행은 Media `SoundExtractor`(다른 FFmpeg 작업처럼 셸 없이, 작업 개체 안에서).
- 음량·페이드는 넣지 않는다(원본 소리 그대로). 저장한 파일은 미디어 목록에 더한다(가져오기와 같은 실행 취소 한 단계).

## 6. 프로젝트 파일

- `LinkId`·`Unlinked`는 값이 있을 때만 쓴다. 링크가 없는 프로젝트의 JSON은 예전과 같고, 형식 버전도 2 그대로다(예전 플러그인은 모르는 필드를 무시한다).
- 예전 `.fvproj`의 분리 클립은 링크 없이 열린다 — 지금처럼 따로 움직이고, 같은 구간이면 [사운드 합치기]로 합칠 수 있다.
- 열 때·실행 취소 상태를 읽을 때 고친다(남이 만든 파일일 수 있음): `LinkId`는 16진수 32자까지, 같은 원본의 영상·사운드 둘이어야 짝이고 아니면 링크를 뺀다. 한쪽만 풀렸으면 둘 다 푼 것으로.

## 7. 시험

- Core(리눅스 CI, `SoundSplitTests`): 분리하면 링크, 옮기기(제 트랙에서 따라감·다른 동영상 트랙으로·Alt로 따로 뒤 새 차이 유지·마그네틱 주 트랙의 영상이 이끔·두 영상 바꾸기·빼냈다 같은 경계에 다시 끼우기), 끼워 넣기·지우기로 밀리고 당겨짐, 덮어쓰지 않고 새 트랙으로, 잠긴 짝, 다듬기(마그네틱 앞 줄이기·늘이기에서 트랙을 바꾸지 않음), 분할 두 짝, 삭제·잠긴 짝 링크 풀기, 속도, 빈틈 닫기, 프레임 레이트, 고르기·누른 쪽, 링크 해제·어긋남·싱크 맞추기(0 앞 자르기)·다시 링크, 합치기(실행 취소 한 단계·그래프 같음·예전 프로젝트), 미디어에서 나눠 놓기(마그네틱·여럿 차례로·실행 취소 한 번), 붙여 넣은 사본 링크, 프로젝트 파일(저장·열기·예전 형식·잘못된 링크), 어긋남 글, 그릇·다시 인코딩 여부·FFmpeg 인수
- FFmpeg 통합: AAC → `.m4a` 그대로(ffprobe로 코덱), MP3 그릇에 AAC → WAV로, 클립 구간 2배속 → WAV 0.5초, 합친 뒤 소리가 분리 전과 바이트까지 같음
- 화면(Windows, `SoundSplitTests`): 미디어 패널 [사운드 분리해서 배치](하나·여럿, 실행 취소 한 번), 이름(편집 메뉴·도구 막대·속성 안내)과 Ctrl+Alt+D, 합치기·실행 취소, 함께 고르기·옮기기·Alt로 따로·링크 해제·어긋남·싱크 맞추기·다시 링크·함께 삭제, 사운드를 파일로 저장(원본 코덱·클립 구간 2배속 WAV·미디어 목록)

## 8. 범위 밖 (별도 결정)

- **목소리·음악 분리(음원 분리)**: 원본 사운드에서 배경 음악만, 또는 목소리만 남기기. FFmpeg에는 없고 학습된 분리 모델(ONNX Runtime 또는 별도 도우미 프로세스)이 필요하다 — 모델 내려받기(수십~수백 MB), 처리 시간, 모델 라이선스를 따로 검토한다.
