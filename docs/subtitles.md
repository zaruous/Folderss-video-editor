# 구현 계획 — 자막 트랙 (1단계: SRT 가져오기 + 영상에 입혀 내보내기)

내레이션 영상(쇼츠 등)에 음성 인식으로 만든 SRT 자막을 붙이는 일이 급하다. 지금은 편집기에 자막 기능이 없어 큐마다 화면 크기 PNG를 만들어 이미지 클립으로 깔아야 한다.
이 문서는 1단계 범위와 정한 것을 적는다. 이슈: [#25](https://github.com/zaruous/Folderss-video-editor/issues/25).

## 1. 범위

| 단계 | 내용 |
|---|---|
| **1단계(이번)** | SRT·VTT 가져오기 → "자막" 트랙에 큐 클립, 미리 보기·내보내기 때 영상에 입히기(libass), 속성 패널에서 큐 글 고치기 |
| 2단계 | 트랙 공통 스타일(글꼴·크기·색·윤곽선·그림자·배경 상자·위치·한 줄 최대 폭) 고치기, 재생 헤드에 큐 추가 |
| 3단계 | SRT 내보내기, MP4 안 켜고 끄는 자막 스트림(mov_text) |
| 범위 밖 | 음성 인식으로 자막 만들기(PRD에서 뺀 AI 기능) |

## 2. 정한 것

1. **모델: 새 트랙 종류 대신 동영상 트랙의 표시 `Track.Subtitles`.**
   - 큐는 지금의 글자 클립(`ClipKind.Text`)이다. 그래서 옮기기·다듬기·분할·삭제·실행 취소·저장이 그대로 된다.
   - 자막 트랙에는 글자 클립만 놓을 수 있다(`TimelineEdits.Accepts`). 이름은 "자막"(여러 개면 "자막 2"…), 동영상 트랙 번호에서 뺀다.
   - 프로젝트 형식 버전은 그대로 2다. 버전 2는 아직 배포 전이라 필드를 더해도 된다(배포된 v0.1.0은 버전 1만 읽는다).
2. **입히기: libass.**
   - 렌더 그래프가 자막 트랙마다 그리는 구간 안의 큐로 ASS 파일 하나를 만들고(`plan.TextFiles`, 렌더 뒤 지움), 그 트랙 자리에서 `ass=filename=…` 필터를 건다.
   - `PlayResX/Y` = 프로젝트 크기. 그래서 미리 보기처럼 작게 그려도 libass가 같은 비율로 줄인다(미리 보기 = 내보내기).
   - 큐 시각은 그리는 구간 시작 기준이고, 프레임 경계에서 한 프레임 어긋나지 않게 **반 프레임 앞**으로 적는다(큐 [S, E) 프레임 → (S−½)/fps ~ (E−½)/fps).
   - 큐 수백 개도 필터 하나라 가볍고, 자동 줄바꿈·윤곽선·그림자를 libass가 한다.
   - FFmpeg에 libass가 없으면 그리기 전에 알아들을 수 있는 오류로 알린다. 플러그인이 받는 빌드와 흔한 배포판 빌드에는 들어 있다.
3. **기본 모양**(2단계에서 고칠 수 있게): 맑은 고딕, 흰 글자 + 검은 윤곽선 + 옅은 그림자, 아래 가운데.
   - 크기는 짧은 변의 6%(1080×1920이면 65px), 윤곽선은 크기의 6%, 아래 여백은 높이의 8%, 좌우 여백은 폭의 6%다.
4. **가져오기**
   - SRT·WebVTT를 자동으로 알아본다. 큐 번호가 없거나 빈 줄이 겹쳐도 읽는다.
   - `<i>` 같은 태그와 `{\an8}` 같은 꾸밈 태그는 빼고, `&amp;` 등은 글자로 바꾼다.
   - 인코딩: BOM(UTF-8·UTF-16) → 엄격한 UTF-8 → 아니면 CP949(한국어 SRT에 흔함).
   - 새 "자막" 트랙을 맨 위에 만들고 SRT 시각(0초 기준) 그대로 놓는다. 겹치는 큐는 앞 큐의 끝을 다음 큐 시작으로 줄인다.
   - 들어오는 곳: 파일 메뉴 "자막 가져오기…", 가져오기 창(Ctrl+I)에서 .srt·.vtt를 고르거나 끌어 놓기.

## 3. 보안·제한 (자막 파일과 프로젝트 파일은 남이 만든 것일 수 있다)

- 자막 파일은 10MB, 큐는 2만 개, 큐 글은 2,000자까지 읽는다. 시각은 0~24시간이고, 끝 ≤ 시작이면 버린다.
- ASS로 옮길 때:
  - `{`·`}`는 꾸밈 태그로 읽히지 않게 전각 괄호로 바꾼다.
  - `\N`·`\n`·`\h` 앞의 역슬래시는 보이지 않는 문자로 끊는다.
  - 줄바꿈은 `\N`으로 쓴다.
  - 쉼표가 든 필드는 글(마지막 필드)뿐이다.
- ASS 파일 이름은 GUID다(클립 Id·글을 쓰지 않음). 필터 값은 지금처럼 `FilterValue`로 감싼다.

## 4. 시험

- Core(리눅스 CI)
  - SRT·VTT 읽기: 경계·잘못된 블록·태그·엔티티·인코딩(UTF-8·BOM·UTF-16·CP949)·제한
  - 가져오기 배치: 트랙 이름, 겹침, 받는 클립 종류, 실행 취소
  - 저장 → 다시 열기
  - ASS 내용: 스타일, 반 프레임 시각, 구간 거르기, 이스케이프
  - 렌더 그래프: `ass` 필터·숨긴 트랙·구간에 큐가 없을 때
  - `-filters` 읽기
- FFmpeg 통합: 큐 시각 프레임은 화면 아래쪽에 흰 글자 픽셀이 있고 위쪽은 없다. 큐 밖 시각에는 없다. 미리 보기 = 내보내기.
- 화면(Windows): 파일 메뉴로 SRT를 가져오면 "자막" 트랙에 큐가 생기고 미리 보기에 글자가 보인다. 속성 패널에서 글을 고치면 바뀐다.
